# Material library

Starter materials from [ambientCG](https://ambientcg.com), released under CC0 1.0 (public domain):
free to use, change and ship, no attribution required (we credit them anyway).

Each folder: color.jpg, normal.jpg (OpenGL), roughness.jpg, metal.jpg (metals), preview.jpg. library.json lists
name, category, the metres one repeat covers, and the Source surface type used in CS:S exports.
