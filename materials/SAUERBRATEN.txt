Textures from Cube 2: Sauerbraten
=================================

MALLET ships these texture packs from Cube 2: Sauerbraten (http://sauerbraten.org) because each pack's own license
allows it. Thank you to every artist below! Each pack's license file is in sauerbraten_licenses/<pack>/.

Sauerbraten's README says its media isn't free to reuse unless a pack says so, so every pack was checked by hand
(2026-11-07). In MALLET they're in the material picker as "Sauerbraten · <pack>".

Share-alike packs (sheik, painkillah): changed versions must use the same license.
